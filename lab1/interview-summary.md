# 两轮书面沟通精简记录

项目：校园二手交易系统
沟通日期：两轮均为 2026-10-24（用户确认）；未提供具体时分，不补造时间。
材料形式：第一轮甲方书面需求说明；第二轮本聊天乙方提问、用户提供甲方答复。
说明：下列 INT 行为经用户授权的精简整理，不冒充逐字原话；完整原文保存在第二部分的输入材料区。第一轮没有提供乙方提问，不补造访谈问题。

INT-01 第一轮书面需求采集
INT-01-L001 甲方：做校园二手交易网站，解决信息分散、售出未更新和重复预约；每条商品一件物品，线下联系、付款和交接，不做支付、物流、聊天、评价、推荐或学校认证。
INT-01-L002 甲方：普通账号可兼买卖角色，以唯一用户名、密码注册登录；管理员凭部署时一次性邀请码注册。未登录只可浏览，用户不得越权，管理员不代替双方完成交易。
INT-01-L003 甲方：商品填标题、分类、描述、新旧、价格、地点，价格为0.01至99999.99元且最多两位小数；草稿提交审核，驳回须说明原因，修改需回草稿重审，有有效预约不得修改。
INT-01-L004 甲方：卖家可下架，管理员可违规下架并锁定；解锁后可改草稿重审。已售出仅追加违规记录，历史不删除。卖家下架适用状态以第二轮补充为准。
INT-01-L005 甲方：买家仅预约已发布的他人商品并保存当时标题、价格、地点。等待确认时买家可取消，卖家可接受或说明原因拒绝；待交接时任一方说明原因可取消；卖家确认完成后不可撤销，不自动处理超时。
INT-01-L006 甲方：商品八态为草稿、待审核、已驳回、已发布、已预约、待交接、已售出、已下架；预约六态为等待确认、待交接、已取消、已拒绝、已终止、已完成。未列明转换禁止，锁定是附加标记。
INT-01-L007 甲方：保存用户角色、商品卖家、预约买家、审核违规和日志，编号及用户名唯一；每件商品最多一条有效预约。相关状态与成功日志同步保存，失败全部回滚；金额按分存，成交采用预约价。
INT-01-L008 甲方：支持关键词、分类、价格、状态组合查询并分页。公开列表仅含非违规的已发布、已预约、待交接和已售出；卖家查自己的全部，管理员查全部。统计商品状态数量、完成笔数与金额，日志按操作者、对象、类型、时间查询。
INT-01-L009 甲方：并发预约仅一人成功；重复请求不重复执行；旧页面按当前状态检查；非法或越权不改业务数据，并保留表单其他合法输入。
INT-01-L010 甲方：安全验收包含四类越权各至少两例且全部拒绝、数据不变，数据库和日志无明文密码。可靠性验收为20人并发预约重复10轮均唯一有效、模拟保存失败无部分更新、重启后数据可查；性能按第二轮补充。

INT-02 第二轮跟进沟通（精简七问七答）
INT-02-L001 乙方：卖家可以在哪些状态下下架？有预约时如何保持一致？
INT-02-L002 甲方：已发布、已预约、待交接均可下架。有效预约下架须填原因，商品下架、预约终止、成功日志同时生效或全部不生效；买家可查终止原因，已售出不可下架。
INT-02-L003 乙方：双方联系方式何时填写、何时可见，结束后还能看吗？
INT-02-L004 甲方：买家预约时填写，预约成功卖家可见；卖家接受时填写，接受成功买家可见。仅按有效预约阶段展示；取消、拒绝、终止、完成后双方连历史页和直接请求也不能看。管理员因管理可查私有留存，公开页和日志不展示；本期不能修改联系方式，填错需取消重约。
INT-02-L005 乙方：卖家误确认完成或交接有争议时怎么办？
INT-02-L006 甲方：卖家单方完成前必须二次确认，提示“请确认已经完成线下交接，完成后不可撤销”。误操作或争议保留记录、线下解决；不做申诉、仲裁、退款或状态纠错，管理员也不能恢复在售。
INT-02-L007 乙方：怎样区分重复请求、新操作和失败重试？退出后重发如何处理？
INT-02-L008 甲方：以同一用户、对象的同一次操作识别，不能仅凭用户商品相同；成功重发复用结果、处理中不重复执行，临时保存失败且无更新可重检后重试；非法、越权、冲突修正后提交及取消后重约均为新操作。所有重发先查登录与当前权限，退出后拒绝。
INT-02-L009 乙方：失败操作是否记日志，业务回滚后如何保留，哪些内容不能记？
INT-02-L010 甲方：服务端收到的越权、状态冲突、非法输入、保存失败都留失败日志，含时间、类型、对象（如有）、已登录操作者、请求标识和原因，未登录不虚构身份。失败日志独立保留，数据库故障可先写本地、恢复后供管理员查；成功日志与业务同步。不得记密码、联系方式、邀请码原文或含这些内容的完整请求，不记录每次本地输入错误。
INT-02-L011 乙方：关键词、价格和统计日期的边界是什么？
INT-02-L012 甲方：关键词匹配标题或描述，其他条件同时满足；价格上下限均包含，下限高于上限拒绝。按北京时间、实际完成时间统计，包含结束日期全天，金额用预约价，取消、拒绝、终止不计。
INT-02-L013 乙方：100次查询、1秒计时及测试环境如何约定？
INT-02-L014 甲方：20人每人5次，共100次，可做5轮；1万商品、每页20条，至少95次1秒内显示文字列表，失败超时不剔除。计时从客户端发出请求到列表显示，含网络、服务端和渲染，不含图片和输入。工程师提出设备、浏览器、部署、网络及覆盖有/无结果的查询组合，甲方确认后固定；硬件网络尚待确认，不能无条件承诺。

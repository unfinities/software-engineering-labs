# 甲方选题清单

已选题：校园二手交易系统。下表保留课程允许的五个项目作为原约束，其中二手交易行是本项目必须覆盖的最低范围。

| 项目 | 至少覆盖的业务 |
| --- | --- |
| 多人共享记账系统 | 创建账本、邀请/退出、成员权限；收支新增、修改、撤回、审核、驳回、作废；按类别/成员/时间/金额查询；预算、分类统计、成员统计、结算；已审核记录更正、非法金额、重复提交；结算前后数据一致和关键日志 |
| 二手交易系统 | 买家/卖家/管理员注册登录与权限；商品草稿、提交审核、发布、修改、下架、违规处理；关键词/分类/价格/状态查询；预约、取消预约、卖家确认、交易完成；多人竞争同一商品、重复预约、旧页面操作 |
| 外卖点餐与配送系统 | 顾客/商家/配送员/管理员权限；店铺、菜品、营业状态、库存；查询、购物车、下单并保存下单价；接单、制作、分配配送、送达、完成；售罄/改价/地址异常/拒单/配送失败；重复下单、接单超时、取消退款、状态一致及日志 |
| 酒店预订系统 | 顾客/酒店工作人员/管理员权限；酒店、房型、每日库存、价格、停售；城市/日期/人数/房型/价格查询；预订、确认、修改、取消、入住、退房；最后一间房竞争、重复预订、房态变化、跨日库存、无房、临时停业及日志 |
| 活动票务与报名系统 | 参与者/组织者/检票员/管理员权限；活动、场次、票种或类别的创建、审核、发布、修改、取消；查询、报名、取消、候补和自动递补；最后名额竞争、重复报名、截止后报名；签到/验票、重复签到、缺席、活动取消；名单导出、容量统计及日志 |

## 选择记录（访谈后填写）

- 项目名称：校园二手交易系统。
- 甲方目标：解决商品信息分散、售出后未更新、多人重复预约。
- 纳入范围：发布审核、组合查询、预约与取消、卖家确认完成、违规处理、统计日志。
- 不实现：线上支付、物流、即时聊天、评价推荐、学校认证、自动超时、联系方式修改、申诉仲裁退款及交易状态纠错。

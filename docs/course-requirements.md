## 需求字段（顺序固定）

需求标题为 `## REQ-001 需求名称`。依次填写：类型、来源、优先级、状态、需求描述、前置条件、正常结果、异常或边界情况、验收方法、关联需求。

类型为功能需求/非功能需求/约束；优先级为高/中/低；状态为已确认/待确认/已拒绝/已变更。来源可为实际 INT 行号或本表 COURSE 编号。业务细节缺少确认时不能标为已确认。

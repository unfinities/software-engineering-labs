# 校园二手交易系统业务分析

依据：2026-10-24两轮书面材料，INT索引见chat.txt；本文件是需求分析，不指定数据库或开发框架。

## 1 用户与权限

| 角色 | 可执行操作 | 数据范围/禁止项 |
| --- | --- | --- |
| 未登录者 | 浏览公开商品 | 不可预约、修改、审核或获取私有联系方式 |
| 买家 | 预约他人商品、按阶段取消、查看自身历史 | 不得预约本人商品、查看无关预约；结束后不得读取联系方式 |
| 卖家 | 自己商品的草稿、提交、撤回、修改、下架；接受/拒绝预约、确认完成 | 有有效预约不得修改；已售出不可回退；下架三态以INT-02-L002为准 |
| 管理员 | 审核、违规下架/锁定/解锁、平台统计日志、因管理查看私有联系方式 | 普通注册不能取得管理员角色；不替双方完成交易、不回退已售出 |

一个普通账号可兼任买卖角色。授权基于当前登录、角色及对象归属，重发请求同样验证。

## 2 正常流程及分支

| 阶段 | 参与者及前置条件 | 正常结果 | 取消/失败分支 |
| --- | --- | --- | --- |
| 注册登录 | 普通用户注册唯一用户名；管理员用一次性邀请码 | 当前身份可执行授权操作 | 重名、无效/已用邀请码或未登录受保护操作拒绝 |
| 发布审核 | 卖家填完整合法商品，提交待审 | 管理员通过后已发布 | 驳回带原因；待审撤回草稿才可修改 |
| 查询预约 | 买家查已发布的他人商品并填联系方式 | 保存快照，商品已预约，预约等待确认 | 竞争失败仅提示，不重复占用 |
| 卖家处理 | 卖家查看买家联系，接受时填自身联系 | 双方待交接，买家可查卖家联系 | 拒绝带原因或买家取消后恢复发布 |
| 线下交接 | 待交接时双方自行联系、付款交物 | 系统尚不记录已完成 | 任一方说明原因可取消，恢复发布 |
| 完成记录 | 卖家确认二次不可撤销提示 | 商品已售出、预约已完成，保存完成时刻及预约价 | 不确认则不更新；完成后不能撤销 |
| 下架处理 | 卖家三态下架或管理员违规处理 | 商品下架，有效预约终止并保留原因 | 业务与成功日志任一写入失败全部不生效 |

## 3 商品状态转换

| 当前状态 | 允许转移及动作 | 禁止/约束 |
| --- | --- | --- |
| 草稿 | 提交至待审核 | 不得直接发布 |
| 待审核 | 审核通过至已发布；驳回至已驳回；撤回至草稿；违规下架至已下架 | 不得直接修改；锁定禁止提交 |
| 已驳回 | 修改至草稿，再提交 | 不得跳过重新审核 |
| 已发布 | 预约至已预约；撤回修改至草稿；下架至已下架 | 预约需当前状态合法、非本人商品 |
| 已预约 | 卖家接受至待交接；取消/拒绝至已发布；下架至已下架 | 不得直接完成或修改 |
| 待交接 | 卖家完成至已售出；任一方带原因取消至已发布；下架至已下架 | 不得修改；完成与取消不可同时生效 |
| 已售出 | 无回退；违规仅追加处理记录 | 不可下架、取消、重约、恢复在售 |
| 已下架 | 未锁定时修改至草稿，再提交 | 锁定需管理员解除后才可修改 |

未列转换均禁止。违规锁定是附加标记，不替代八种业务状态。

## 4 预约状态及配对

| 预约当前状态 | 允许转移 | 对应商品变化 |
| --- | --- | --- |
| 等待确认 | 接受至待交接；买家取消至已取消；卖家拒绝至已拒绝；下架至已终止 | 接受后待交接；取消/拒绝恢复已发布；下架后已下架 |
| 待交接 | 卖家完成至已完成；任一方带原因取消至已取消；下架至已终止 | 完成后已售出；取消恢复已发布；下架后已下架 |
| 已取消/已拒绝/已终止/已完成 | 不复用旧记录，不回退 | 后续重新预约必须新建记录；已售出不能重新预约 |

有效预约仅等待确认、待交接。已预约商品恰有一条等待确认预约；待交接商品恰有一条待交接预约；其他商品状态无有效预约。

## 5 数据与一致性

| 数据对象 | 必要信息与关系 | 业务约束 |
| --- | --- | --- |
| 用户及角色 | 用户标识、唯一用户名、受保护密码、普通/管理员权限 | 普通账号可兼买卖；管理员邀请码一次有效 |
| 商品 | 标识、卖家、标题分类描述新旧、分单位价格、地点、八态、锁定标记 | 一条一物，价格0.01至99999.99且两位小数；有效预约时不可改 |
| 预约 | 标识、商品、买家、阶段、标题/价格/地点快照、双方私有联系、结束原因、完成时刻 | 同一商品最多一条有效预约，结束后不复用编号；成交用预约价 |
| 审核与违规记录 | 商品、管理员、结论、原因与历史 | 违规已售出仅追加，不删除历史 |
| 成功操作日志 | 操作者、时间、对象、动作、前后状态、结果和适用原因 | 业务与成功日志同步，重发不重复，不可改删 |
| 失败/故障日志 | 时间、类型、对象如有、已登录操作者、请求标识、原因 | 不随失败业务回滚；数据库故障先本地留痕，恢复后管理员查 |

不把用户和商品相同等同于同次操作。成功重发复用原结果但仍先核验当前权限和联系方式可见范围；保存失败无部分更新可重试，取消后重约为新业务。

## 6 联系方式矩阵

| 阶段/访问者 | 卖家读买家联系 | 买家读卖家联系 | 其他范围 |
| --- | --- | --- | --- |
| 等待确认 | 买家预约成功后可读 | 卖家未接受并提供前不可读 | 无关用户、公开列表、日志均不可见 |
| 待交接 | 可读 | 卖家接受成功后可读 | 管理员因管理需要可查 |
| 取消/拒绝/终止/完成 | 不可读 | 不可读 | 仍私有留存，管理员因管理可查 |

状态限制同时作用于页面、历史页、直接请求及重发；本期不提供联系方式修改，填错取消后重约。

## 7 查询、统计与异常验收

关键词对标题或描述做包含匹配；分类、价格、状态条件与其同时满足。价格闭区间，倒置拒绝。公开结果仅非违规的已发布、已预约、待交接及已售出；卖家和管理员按权限查询。

成交统计按北京时间的实际完成时间，开始日00:00起、结束日次日00:00前；只计完成记录，金额用预约价格，取消/拒绝/终止不计。另统计授权范围内各状态商品数量。

| 场景 | 处理结果 | 验收证据 |
| --- | --- | --- |
| 最后商品并发预约 | 仅一成功，其余不产生有效预约 | 20人并发，10轮核对状态和日志 |
| 重复、处理中、保存失败重试 | 成功复用、处理中不重执、故障后重检 | 请求标识、返回及业务/日志次数 |
| 修改与预约、取消与完成冲突 | 仅符合当前状态的操作生效 | 不相容状态不同时出现 |
| 有预约下架 | 原因可查，商品下架及预约终止整体保存 | 任一保存点失败无部分更新 |
| 结束后访问联系 | 包括历史和直接请求均拒绝双方访问 | 阶段和角色交叉访问矩阵 |
| 数据库失败 | 成功业务回滚，失败日志独立保留 | 本地故障记录、恢复后管理员可查 |
| 日期和价格边界 | 价格两端包含，结束日全天包含 | 边界记录的筛选与金额核算 |
